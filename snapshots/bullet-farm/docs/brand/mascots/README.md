# Bullet Farm mascot concepts

Status: **branding sketches; not product or release authority**  
Last reviewed: 2026-08-25

Five sticker-first mascot briefs for image generators (Flux, Midjourney, Ideogram, Recraft, or similar).
Each file is one concept: a short why, a 5–10 sentence prompt you can paste, a negative prompt, and a die-cut note.

These are not Gas Town parody characters and must not copy their Mayor, polecat, beads, or town-map marks.
The contrast is architectural: a chaotic shared street versus one fenced plot and one verified line to `main`.

## How to generate

- Aspect: `1:1` first, then a second pass at `3:2` for a hero README banner.
- Style lock (use in every prompt): thick rounded sticker outline, 3–5 flat colors, soft cel shade, no tiny text, no photoreal skin, no trademarked characters.
- Background: transparent or a single cream/night field so the die-cut reads on both GitHub light and dark.
- If the model writes letters, discard that take. Add the wordmark later in Figma.
