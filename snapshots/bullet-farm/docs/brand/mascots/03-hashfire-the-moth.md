# 3. Hashfire the Moth

**Why this wins.** Evidence is Bullet Farm’s real magic trick — a green result that does not name an exact Candidate is just theater — and almost no coding-agent brand has a mascot for that. Hashfire is a lantern moth whose glass abdomen lights only when the constellation inside matches, a living proof root. Its joke is that it stays dark for an unbound green status. As a sticker it is prettier than the goat, more “I work on compilers / verification” than the combine, and it becomes the mark for docs, CI, and the Evidence Bay without looking like a generic firefly NFT.

## Image prompt (paste this)

A die-cut sticker mascot of a large, elegant lantern moth facing slightly left, wings spread in a shallow V so the shape is a wide hex-ish shield. Forewings are ink-dark with cream vein traces; hindwings are translucent brass. The abdomen is a smooth glass lantern containing a tiny, sharp constellation of nodes and edges that looks like a git tree — dots and links only, no letters, no hex digits. A thin signal-green filament rings the lantern as if a fence epoch were a filament. The moth’s antennae are two precise forks, not feathery mess. One wing edge clips a dull, unlit paper lantern in the background (an unbound status light) so the contrast is proof-root bright versus status-light dim, but the background lantern is small and receding. Flat cel-shaded, thick rounded outline, four colors, no sparkle spam, no photoreal insects, no skulls. Centered on transparent background, high contrast for dark-mode GitHub, kiss-cut friendly.

## Negative prompt

photoreal moth, scary horror insect, blood, flame inferno, candle wax drips, tarot, crypto NFT look, QR codes, readable hashes, hexadecimal text, cowboy, saloon, trademark logos, extra insects, city skyline
