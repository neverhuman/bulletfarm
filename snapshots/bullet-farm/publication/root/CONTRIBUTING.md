# Contributing to Bullet

Start with the [contribution guide](bullet-farm/CONTRIBUTING.md) for source
onboarding, verification and submitting a change to the owning member repository.
The [README](README.md) explains the public aggregate and its four source members.

Root files are generated from the Hub templates in
`bullet-farm/publication/root/`. Change those templates in the Hub; a direct
edit to an aggregate copy will fail publication verification.
